# Speecher

Консольное приложение для голосового ввода текста в Windows. Нажимаете горячую клавишу, говорите, нажимаете ещё раз — распознанный текст попадает в буфер обмена или, по отдельной горячей клавише, печатается в активное окно, будто вы набрали его с клавиатуры.

Распознавание работает локально, без облачных сервисов, на модели [Whisper](https://github.com/openai/whisper) (`ggml-large-v3-turbo`) через [Whisper.net](https://github.com/sandrohanea/whisper.net). Поддерживаются русский и английский языки, язык определяется автоматически.

## Возможности

- Запуск и остановка записи одной горячей клавишей (по умолчанию `Ctrl+Alt+Space`).
- Ввод текста в любое приложение через эмуляцию клавиатуры (Unicode, раскладка не важна).
- Автоматическое определение языка: русский или английский.
- Ускорение на GPU через Vulkan (по умолчанию) или CUDA 12, режим выбирается в `settings.json`. Если подходящей видеокарты нет — работа на CPU.
- Голосовые команды: новая строка, табуляция, отмена последнего ввода.
- Фраза по умолчанию копируется в буфер обмена. Отдельная горячая клавиша (по умолчанию `Ctrl+Alt+T`) переключает следующую фразу на печать в активное окно.
- Распознавание системного звука: отдельная горячая клавиша (по умолчанию `Ctrl+Alt+S`) переключает следующую запись с микрофона на то, что играет на устройстве вывода по умолчанию (видео, игра, звонок).
- Расшифровка готовых аудиофайлов: отдельный режим из jumplist, принимает путь к файлу или папке.
- Отсечение слишком коротких записей и тишины.
- История распознанных фраз в `history.jsonl`.
- Портативность: все файлы хранятся рядом с exe, в системе ничего не устанавливается.

## Требования

- Windows 10 или 11, x64.
- Микрофон.
- Около 2 ГБ свободного места под модель; для режима `Cuda` — ещё примерно 1 ГБ под библиотеки.
- Для ускорения на GPU — дискретная видеокарта с драйвером, поддерживающим Vulkan, и примерно 1,5 ГБ свободной видеопамяти. Для режима `Cuda` — видеокарта NVIDIA; CUDA Toolkit ставить не нужно.
- Для сборки — [Git](https://git-scm.com/download/win) и [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) (x64).
- Интернет при первом запуске: для скачивания модели, а в режиме `Cuda` — ещё и библиотек CUDA.

## Установка

1. Установите [Git](https://git-scm.com/download/win) и [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0). Проверьте, что SDK установлен:

   ```powershell
   dotnet --list-sdks
   ```

   В списке должна быть версия `9.0.x`.

2. Установите или обновите драйвер видеокарты: Vulkan входит в состав драйвера. Для режима `Cuda` нужен драйвер NVIDIA версии 528 или новее с [сайта NVIDIA](https://www.nvidia.com/drivers). Без подходящей видеокарты этот шаг пропустите: приложение будет работать на CPU, но медленнее.

3. Клонируйте репозиторий и перейдите в его папку:

   ```powershell
   git clone https://github.com/Dalidovich/Speecher.git
   cd Speecher
   ```

4. Соберите приложение:

   ```powershell
   dotnet publish src/Speecher -c Release -o publish
   ```

   Зависимости NuGet скачаются автоматически. В папке `publish` появятся `Speecher.exe` и папка `runtimes` с нативными библиотеками Whisper. Это self-contained сборка: .NET для её запуска не нужен, и папку `publish` можно скопировать на другой компьютер. Держите `runtimes` рядом с exe.

5. Запустите приложение:

   ```powershell
   .\publish\Speecher.exe
   ```

   Первый запуск займёт время: скачивается модель (около 1,6 ГБ). Когда в консоли появится `Ready`, можно диктовать.

6. Проверьте строку `Backend:` в консоли. `Vulkan (имя видеокарты)` или `CUDA` — распознавание идёт на видеокарте, `CPU (N threads)` — на процессоре. Если видеокарта есть, а написано `CPU`, строкой выше будет предупреждение с причиной: обновите драйвер или укажите видеокарту в `GpuName`. В режиме `Cuda` также удалите папку `publish/runtime`, чтобы библиотеки CUDA скачались заново.

## Первый запуск

При первом запуске приложение:

1. Создаёт `settings.json` с настройками по умолчанию.
2. Скачивает модель `ggml-large-v3-turbo.bin` (около 1,6 ГБ) с Hugging Face в папку `models`.
3. В режиме `Cuda`, если найден драйвер NVIDIA, — скачивает библиотеки CUDA runtime (`cudart`, `cublas`) с сервера NVIDIA в папку `runtime/cuda` и сверяет их контрольные суммы. Если скачать не удалось, приложение продолжает работу на CPU.

Последующие запуски работают без интернета.

## Режимы

У приложения два режима: диктовка и расшифровка файлов.

| Режим | Запуск | Источник звука | Куда попадает текст |
|---|---|---|---|
| [Диктовка](#диктовка) | `Speecher.exe` без аргументов | Микрофон или, по флагу, устройство вывода | Буфер обмена или, по флагу, активное окно |
| [Расшифровка файлов](#расшифровка-файлов) | Пункт jumplist «Transcribe files» или `Speecher.exe --files` | Аудиофайлы | Консоль и буфер обмена |

Чтобы открыть jumplist, закрепите `Speecher.exe` на панели задач (или запустите его хотя бы раз) и щёлкните по значку правой кнопкой.

### Диктовка

- **Запуск:** `Speecher.exe` без аргументов (двойной щелчок по exe).
- **Источник звука:** микрофон из `MicrophoneName`, при пустом значении — системный микрофон по умолчанию. Для одной записи можно переключиться на [системный звук](#системный-звук).
- **Результат:** фраза целиком помещается в буфер обмена, в окно ничего не печатается. Для одной фразы можно включить [печать текста](#печать-текста).
- **Голосовые команды:** работают при записи с микрофона, нажатия клавиш уходят в активное окно.
- **История:** фразы пишутся в `history.jsonl`.

Управление:

1. Дождитесь сообщения `Ready` в консоли.
2. Нажмите горячую клавишу — начнётся запись.
3. Нажмите её ещё раз — запись остановится, и текст распознается.

Повторное нажатие во время распознавания или печати отменяет операцию. Запись автоматически останавливается по достижении `MaxRecordingSeconds`. Выход — `Ctrl+C` или закрытие окна консоли. Горячие клавиши регистрируются глобально, поэтому два экземпляра в режиме диктовки одновременно не запускаются.

Флаги [системного звука](#системный-звук) и [печати текста](#печать-текста) независимы и сочетаются: если взведены оба, системный звук распознаётся и печатается в активное окно.

### Расшифровка файлов

- **Запуск:** пункт «Transcribe files» или `Speecher.exe --files`.
- **Источник звука:** аудиофайлы. Ogg Opus (голосовые сообщения Telegram) декодируется встроенным декодером, остальные форматы — средствами Windows Media Foundation: `wav`, `mp3`, `m4a`, `aac`, `wma`, `flac`, а также звуковые дорожки видео, например `mp4`.
- **Управление:** без горячей клавиши. После загрузки модели консоль запрашивает путь к файлу или папке и повторяет запрос после каждой обработки. Путь можно вводить в кавычках, например перетащив файл в окно консоли. Для папки приложение показывает число найденных файлов и просит подтверждение: `Enter` — продолжить, любой другой ввод — отмена.
- **Результат:** для файла текст выводится в консоль и копируется в буфер обмена. Для папки расшифровываются все файлы, включая вложенные: в консоль выводятся путь к файлу и его текст, записи отделены разделителем, буфер обмена не используется. Для файлов, которые не являются аудио, выводится ошибка, и обработка продолжается.
- **Голосовые команды:** не применяются.
- **История:** в `history.jsonl` не пишется.

Горячие клавиши в этом режиме не регистрируются, поэтому его можно держать открытым одновременно с любым другим.

### Системный звук

Флаг, который переключает одну запись с микрофона на системный звук. Работает в режиме диктовки.

- **Включение:** горячая клавиша из `SystemAudioHotkey`, по умолчанию `Ctrl+Alt+S`. Повторное нажатие снимает флаг. В консоли появляется `System audio armed for the next recording` или `System audio disarmed`.
- **Когда действует:** флаг забирается в момент начала записи. Если нажать клавишу во время записи, распознавания или печати, флаг взведётся для следующей записи, а текущая продолжится с прежним источником.
- **Сброс:** сразу после начала записи. Следующая запись снова идёт с микрофона.
- **Источник звука:** то, что вы слышите: устройство вывода Windows по умолчанию, весь звук от всех приложений сразу (видео, игра, звонок). Устройство определяется заново в начале каждой записи, поэтому переключение с колонок на наушники подхватывается без перезапуска; его имя выводится в консоль строкой `Capturing system audio from:`. Если за время записи ничего не играло, запись пропускается.
- **Результат:** фраза копируется в буфер обмена, а при взведённой [печати текста](#печать-текста) — печатается в активное окно.
- **Голосовые команды и скрипты:** отключены, чтобы фраза «отмена» из видео не стёрла ваш текст.

### Печать текста

Флаг, который переключает одну фразу с копирования в буфер на печать в активное окно. Работает в режиме диктовки, в том числе вместе с [системным звуком](#системный-звук).

- **Включение:** горячая клавиша из `TypeTextHotkey`, по умолчанию `Ctrl+Alt+T`. Повторное нажатие снимает флаг. В консоли появляется `Type text armed for the next recording` или `Type text disarmed`.
- **Когда действует:** флаг можно взвести в простое или во время записи — он применится к этой записи. Флаг забирается в момент остановки записи; если нажать клавишу во время распознавания или печати, флаг взведётся уже для следующей записи.
- **Сброс:** после одной записи при любом исходе — текст напечатан, запись пропущена, отменена, ничего не распознано или распознана голосовая команда.
- **Результат:** фраза печатается в активное окно эмуляцией клавиатуры, после неё нажимается `Enter`. Буфер обмена не меняется. Перед печатью приложение ждёт, пока вы отпустите `Ctrl`, `Alt`, `Shift` и `Win`, чтобы зажатые модификаторы не превратили текст в сочетания клавиш. Перед остановкой записи поставьте курсор в поле ввода нужного приложения.

## Голосовые команды

Если фраза целиком совпадает с командой (без учёта регистра и знаков препинания), вместо текста выполняется действие:

| Действие | Фразы по умолчанию | Что делает |
|---|---|---|
| `Enter` | «новая строка», «new line» | Нажимает `Enter` |
| `Tab` | «таб», «tab» | Нажимает `Tab` |
| `Undo` | «отмена», «undo» | Стирает `Backspace`-ом последний напечатанный фрагмент |

Список фраз можно изменить в `settings.json`.

## Запуск скриптов по фразе

В секции `ScriptTriggers` можно задать правила: если распознанный текст подходит под регулярное выражение, запускается указанный скрипт или exe.

```json
"ScriptTriggers": {
  "Enabled": true,
  "Rules": [
    { "Pattern": "^открой калькулятор\\W*$", "Path": "calc.exe", "OutputText": false },
    { "Pattern": "\\bзаметка\\b", "Path": "scripts\\note.bat", "OutputText": true },
    { "Pattern": "^выключи звук\\W*$", "Command": "nircmd mutesysvolume 1" },
    { "Pattern": "^сохрани буфер\\W*$", "Shell": "PowerShell", "Command": "Get-Clipboard | Add-Content \"$env:USERPROFILE\\clips.txt\"" }
  ]
}
```

В каждом правиле указывается либо `Path`, либо `Command`.

- Правила проверяются по порядку, запускается только первое подошедшее.
- Регулярное выражение применяется к тексту как есть, без учёта регистра. Whisper обычно ставит точку в конце фразы — учитывайте это в шаблоне.
- `Path` — абсолютный путь, путь относительно папки с exe или имя программы из `PATH`. Переменные окружения вида `%USERPROFILE%` раскрываются. Файл открывается так же, как двойным щелчком, поэтому подходят `.exe`, `.bat`, `.cmd` и другие типы с назначенной программой.
- `Command` — команда оболочки, которая выполняется в скрытом окне из папки с exe. `Shell` выбирает оболочку: `Cmd` (по умолчанию, `cmd.exe /c`) или `PowerShell` (`powershell.exe -NoProfile -Command`). Работают конвейеры, перенаправления, `&&` и переменные окружения. Если команда завершилась с ненулевым кодом, в консоли появится предупреждение.
- `OutputText`: `false` — текст не вставляется, фраза работает как команда; `true` — скрипт запускается и текст выводится как обычно.
- Голосовые команды проверяются раньше скриптов. Как и они, скрипты работают только при записи с микрофона.

## Настройки

Файл `settings.json` лежит рядом с exe и создаётся автоматически:

```json
{
  "Hotkey": "Ctrl+Alt+Space",
  "TypeTextHotkey": "Ctrl+Alt+T",
  "SystemAudioHotkey": "Ctrl+Alt+S",
  "MicrophoneName": "",
  "MaxRecordingSeconds": 120,
  "MinRecordingSeconds": 0.5,
  "SilenceThresholdDbfs": -45,
  "Backend": "Vulkan",
  "GpuName": "",
  "CpuThreads": 0,
  "Api": {
    "Endpoint": "",
    "RequestMethod": "",
    "HealthEndpoint": "",
    "HealthMethod": "",
    "HealthResponseProperty": "",
    "HealthResponseValue": "",
    "AudioContentType": "",
    "LanguageParameter": "",
    "Language": "",
    "TextResponseProperty": "",
    "LanguageResponseProperty": "",
    "TimeoutSeconds": 0,
    "Headers": {}
  },
  "VoiceCommands": {
    "Enter": ["новая строка", "new line"],
    "Tab": ["таб", "tab"],
    "Undo": ["отмена", "undo"]
  },
  "ScriptTriggers": {
    "Enabled": false,
    "Rules": []
  }
}
```

| Параметр | Описание |
|---|---|
| `Hotkey` | Горячая клавиша. Модификаторы `Ctrl`, `Alt`, `Shift`, `Win` и одна клавиша через `+`, например `Ctrl+Shift+F9`. |
| `TypeTextHotkey` | Горячая клавиша [печати текста](#печать-текста), формат как у `Hotkey`. Должна отличаться от `Hotkey` и `SystemAudioHotkey`. |
| `SystemAudioHotkey` | Горячая клавиша [системного звука](#системный-звук), формат как у `Hotkey`. Должна отличаться от `Hotkey` и `TypeTextHotkey`. |
| `MicrophoneName` | Имя микрофона точно как в списке при запуске. Пустая строка — системный микрофон по умолчанию. |
| `MaxRecordingSeconds` | Максимальная длительность записи в секундах. |
| `MinRecordingSeconds` | Записи короче этого значения пропускаются. |
| `SilenceThresholdDbfs` | Порог тишины в dBFS. Если громкость записи ниже порога, она не распознаётся. |
| `Backend` | Режим распознавания: `Vulkan` (по умолчанию), `Cuda`, `Cpu` или `Api`. `Vulkan` и `Cuda` переключаются на CPU, если видеокарта недоступна. |
| `GpuName` | Часть имени видеокарты для режима `Vulkan`, например `GTX 1660`, без учёта регистра. Пустая строка — первая дискретная видеокарта с поддержкой fp16. Если подходящей нет, используется CPU. |
| `CpuThreads` | Число потоков при работе на CPU. `0` — по числу логических процессоров. |
| `Api` | Параметры HTTP-распознавания. Используются только при `Backend: "Api"`; в этом режиме модель и CUDA runtime не загружаются. |
| `VoiceCommands` | Фразы для голосовых команд `Enter`, `Tab`, `Undo`. |
| `ScriptTriggers` | Запуск скриптов по регулярным выражениям, см. [Запуск скриптов по фразе](#запуск-скриптов-по-фразе). При `Enabled: true` некорректное правило останавливает запуск с ошибкой `settings.json: ScriptTriggers.Rules[N].Pattern has an invalid value.` или `...Rules[N].Path/Command has an invalid value.`, если указаны оба поля или ни одного. |

Параметры, которых нет в файле, принимают значения по умолчанию. Если файл повреждён, приложение предупредит об этом и перезапишет его значениями по умолчанию.

### HTTP API

Режим `Api` передаёт записанный звук как моно WAV, 16 кГц, сырыми байтами в заданный `Endpoint`. Все особенности сервиса задаются в секции `Api`: URL, методы запроса и health-проверки, MIME-тип, общий набор HTTP-заголовков, параметр языка и имена полей JSON-ответа. `TimeoutSeconds: 0` оставляет время ожидания неограниченным.

Для сервиса из `WhisperAPIHandler-AGENT-INTEGRATION.md` укажите:

```json
"Backend": "Api",
"Api": {
  "Endpoint": "http://127.0.0.1:5080/api/transcriptions",
  "RequestMethod": "POST",
  "HealthEndpoint": "http://127.0.0.1:5080/health",
  "HealthMethod": "GET",
  "HealthResponseProperty": "status",
  "HealthResponseValue": "ready",
  "AudioContentType": "audio/wav",
  "LanguageParameter": "language",
  "Language": "auto",
  "TextResponseProperty": "text",
  "LanguageResponseProperty": "language",
  "TimeoutSeconds": 0,
  "Headers": {}
}
```

Если endpoint не требует health-проверки, оставьте `HealthEndpoint`, `HealthResponseProperty` и `HealthResponseValue` пустыми. Для API без выбора языка оставьте пустым `LanguageParameter`; для ответа без языка — `LanguageResponseProperty`.

## Возможные проблемы

| Симптом | Решение |
|---|---|
| `Failed to register hotkey` | Сочетание уже занято другой программой. Укажите другое в `Hotkey`, `TypeTextHotkey` или `SystemAudioHotkey` в `settings.json`. |
| `Recording device "..." was not found` | Имя в `MicrophoneName` не совпадает ни с одним устройством. Скопируйте имя из списка в консоли или оставьте пустую строку. |
| `Failed to download model` | Нет доступа к huggingface.co. Проверьте интернет или положите `ggml-large-v3-turbo.bin` в папку `models` вручную. |
| Текст не печатается в некоторых окнах | Windows не даёт обычному процессу вводить текст в программы, запущенные от имени администратора. Запустите Speecher тоже от имени администратора. |
| `Vulkan GPU "..." was not found` | Имя в `GpuName` не совпадает ни с одной видеокартой. Исправьте его или оставьте пустую строку. |
| `Skipped: silence` на обычной речи | Микрофон слишком тихий. Увеличьте его громкость в Windows или понизьте `SilenceThresholdDbfs`, например до `-55`. |

## Файлы рядом с exe

| Путь | Содержимое |
|---|---|
| `settings.json` | Настройки |
| `history.jsonl` | История распознанных фраз: время, язык, длительность, текст |
| `models/` | Модель Whisper |
| `runtime/cuda/` | Библиотеки CUDA и кэш компиляции ядер, только в режиме `Cuda` |
| `runtimes/` | Нативные библиотеки Whisper.net |

Если папка с exe недоступна для записи, приложение продолжит работать, но без сохранения настроек и истории.

## Структура проекта

| Папка в `src/Speecher` | Назначение |
|---|---|
| `App/` | Точка входа, жизненный цикл приложения, логирование, пути |
| `Audio/` | Запись с микрофона и системного звука через loopback (NAudio, WASAPI), декодирование аудиофайлов, преобразование в 16 кГц моно |
| `Configuration/` | Модель и загрузка настроек |
| `Dictation/` | Основной цикл: запись → распознавание → ввод, голосовые команды, история |
| `Hotkeys/` | Разбор и регистрация глобальной горячей клавиши |
| `Input/` | Эмуляция клавиатуры через `SendInput`, запись в буфер обмена |
| `Interop/` | P/Invoke-объявления WinAPI |
| `Localization/` | Фразы голосовых команд по умолчанию (ru/en) |
| `Speech/` | Загрузка модели, выбор режима и видеокарты, распознавание речи |
| `Transcription/` | Режим расшифровки файлов: консольный цикл запроса путей |
| `Taskbar/` | Индикатор состояния на значке и jumplist панели задач |
